# 50 Days 50 Projects Challenge

A collection of **51 small HTML, CSS, and JavaScript projects** built to strengthen frontend development skills through hands-on practice. Each project focuses on a specific concept such as DOM manipulation, animations, API integration, event handling, or UI interactions.

> Every project includes its own dedicated **README** with features, screenshots (where applicable), and implementation details.

---

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)

## Getting Started

Clone the repository:

```bash
git clone https://github.com/soumajit11/50-Days-50-Projects.git
```

Move into the project directory:

```bash
cd <50-Days-50-Projects
```

Open any project's `index.html` in your browser, or start a local development server:

```bash
python -m http.server 8000
```

Then open:

```
http://localhost:8000
```
