# Day 01 - Expanding Cards

A responsive interactive UI effect built with HTML, CSS, and JavaScript.

## Overview

A responsive card UI where each panel expands smoothly when clicked, highlighting the selected image and displaying a caption.

## Features

- Clickable panels that expand smoothly
- Animated content reveal on active panel
- Responsive layout for smaller screens
- Uses CSS transitions and JavaScript event handling

## Technologies Used

- HTML5
- CSS3
- JavaScript

## What I Learned

- How to manage class state with JavaScript event listeners
- Creating smooth transitions with CSS
- Building a responsive layout using flexbox

## Project Structure

- `index.html` — project markup and panel content
- `style.css` — styling, transitions, and responsive design
- `script.js` — interactive panel click handling

## How to Run

1. Open `index.html` in a web browser
2. Click any panel to expand it

## Notes

- The layout is optimized for desktop with a mobile fallback that hides the last two cards on narrow screens.
- Background images are loaded via inline styles in the HTML.
